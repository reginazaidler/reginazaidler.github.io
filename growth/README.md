# Yuval Growth Agent - V1

Private-style dashboard (noindex) for collecting and executing marketing opportunities.

## V1
- Daily task dashboard
- Topic filters
- Priority score
- Source URL
- Suggested action and response
- Done tracking in browser localStorage
- Manual opportunity entry

The included task is explicitly a demo, not a claimed live lead.

## Next
Add a GitHub Action that collects public web opportunities from permitted sources, scores them by freshness/relevance/engagement signals, and writes a generated JSON feed. Keep Instagram/TikTok actions human-operated unless an official API permits the specific action.
