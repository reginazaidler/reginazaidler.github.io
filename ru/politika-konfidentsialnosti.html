Политика конфиденциальности

Сайт vainzof.co.il - последнее обновление: 24 мая 2026 г.

Настоящая Политика конфиденциальности описывает, как Юваль Вайнзоф - проверка страховок и пенсии («мы», «я») собирает, использует и защищает персональные данные, предоставленные на сайте vainzof.co.il, в соответствии с Законом Израиля о защите персональных данных, 1981 г., Поправкой 13 к данному Закону (2025 г.) и соответствующими нормативными актами.

Какие данные мы собираем

Мы можем собирать следующие виды данных:

  • Добровольно предоставленные данные: имя, номер телефона и email - при заполнении форм обратной связи.
  • Данные об использовании: просмотры страниц, посещения, источник перехода, тип браузера и устройства, показатели загрузки - через Cloudflare Web Analytics. Этот инструмент не использует cookie или локальное хранилище для статистики и не отслеживает людей между сайтами.
  • Файлы cookie: небольшие текстовые файлы, хранящиеся в браузере для улучшения качества просмотра.

Является ли предоставление данных обязательным

Предоставление персональных данных на данном сайте является полностью добровольным. Законодательных обязанностей по предоставлению данных нет. Однако без имени и номера телефона мы не сможем связаться с вами и оказать консультационную услугу. Статистика посещаемости собирается через Cloudflare Web Analytics без cookie для измерения. Google Analytics на сайте не включён.

Правовое основание для обработки данных

Мы обрабатываем персональные данные на одном из следующих оснований:

  • Согласие: отправка формы обратной связи и/или рассылки - только после явного согласия.
  • Исполнение договора: обработка контактных данных для оказания запрошенной консультационной услуги.
  • Статистика: анализ посещаемости и скорости загрузки через Cloudflare Web Analytics без cookie для измерения.
  • Соблюдение законодательства: хранение документации согласно требованиям финансового регулирования.

Как мы используем данные

  • Ответный контакт для оказания консультационных услуг по страхованию и пенсии.
  • Улучшение содержания сайта и качества обслуживания.
  • Рассылка профессиональных обновлений - исключительно с явного согласия.
  • Соблюдение правовых и регуляторных требований.

Автоматизированная обработка и принятие решений

Сайт не осуществляет автоматизированное принятие решений (профилирование), влияющее на права пользователей. Вся обработка данных осуществляется человеком.

Файлы cookie

Сайт использует cookie для:

  • Статистического анализа: Cloudflare Web Analytics не использует cookie для анализа посещаемости.
  • Функционирования сайта: сохранение базовых настроек пользователя.

Вы можете заблокировать cookie в настройках браузера, однако это может повлиять на качество просмотра.

Передача данных третьим лицам

Мы не продаём, не передаём и не раскрываем ваши персональные данные третьим лицам, за исключением:

  • Cloudflare Web Analytics - статистика посещаемости и загрузки без cookie для измерения. Политика конфиденциальности Cloudflare.
  • Formspree - сервис обработки форм обратной связи.
  • Уполномоченных органов в случаях, предусмотренных законом или судебным решением.

Безопасность данных

Мы принимаем разумные меры безопасности для защиты персональных данных. Сайт работает по зашифрованному протоколу HTTPS. Вместе с тем абсолютная безопасность передачи данных через интернет не гарантируется.

Передача данных за пределы Израиля

Некоторые используемые нами сервисы передают данные на серверы за пределами Израиля:

  • Cloudflare Web Analytics - данные статистики могут обрабатываться за пределами Израиля согласно политике конфиденциальности Cloudflare.
  • Formspree (США) - контактные данные, предоставляемые через формы. Данные передаются в зашифрованном виде (HTTPS) и защищены в соответствии с политикой конфиденциальности Formspree.

Эти сервисы используются для статистики и обработки обращений в соответствии с их политиками конфиденциальности. Контактные данные передаются через форму только при её отправке пользователем.

Хранение данных

Сроки хранения данных по типу:

  • Контактные данные (имя, телефон, email): до 7 лет с даты обращения, в соответствии с требованиями финансового регулирования Израиля.
  • Данные о посещаемости: согласно политике и настройкам сервиса Cloudflare.
  • Файлы cookie: инструмент статистики не использует cookie; cookie внешних сервисов регулируются их собственными политиками.

Ваши права как субъекта данных

В соответствии с Законом Израиля о защите персональных данных, 1981 г., вы имеете следующие права:

  • Право доступа: получить копию персональных данных, хранящихся о вас в наших базах данных.
  • Право на исправление: запросить исправление неточных, неполных или вводящих в заблуждение данных.
  • Право на удаление: запросить удаление персональных данных с учётом законодательных обязательств по хранению (например, требований финансового регулирования).
  • Право на возражение: возразить против обработки ваших персональных данных в целях прямого маркетинга.
  • Право на ограничение обработки: запросить ограничение обработки ваших данных в определённых обстоятельствах (например, при проверке точности данных).
  • Право на переносимость данных: получить предоставленные вами данные в структурированном машиночитаемом формате и передать их другому оператору - если обработка основана на согласии.
  • Право на отзыв согласия: в любое время отозвать согласие на получение обновлений и маркетинговых материалов, обратившись к нам или нажав на ссылку отписки.
  • Право на жалобу: обратиться в Управление по защите персональных данных Израиля (gov.il/privacy) по любому вопросу, связанному с обработкой ваших данных.

Для реализации своих прав обращайтесь к нам по контактным данным ниже. Мы рассмотрим запрос в течение 30 дней.
